# Security policy

EchoWave is a pre-release project. Do not include credentials, signed media URLs, private tokens, or personal data in public bug reports.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for the EchoWave repository when available. If private reporting is unavailable, contact the repository maintainer through the contact method listed on the repository profile and include only the information needed to reproduce the issue. Allow time for a fix before public disclosure.

For playback/network reports, include app version, Android version, device model, approximate time, and redacted error codes. Remove account data, request headers, cookies, PO tokens, signed URLs, and full media URLs from logs.

This project has no formal response-time guarantee or supported production release at this time.
