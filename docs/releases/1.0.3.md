# EchoWave 1.0.3

EchoWave 1.0.3 is a free, independent Android music player. It is not affiliated with or endorsed by YouTube, Google, or Spotify.

## What's new

- Update links and local update notifications now open the EchoWave download website, where the latest APK is easy to find.
- The website now explains how to download and install an update while keeping local music and settings.

## Install

Open the [EchoWave download page](https://echowave-website.vercel.app/), tap **Download APK**, open the downloaded file, and tap **Update**. If Android asks, allow installs from your browser or file manager. Android 8.0 (API 26) or newer is required. Do not uninstall first; installing over the existing app with the same signing key preserves local app data.

## Important provider and content notice

Authorization to use the project's undocumented YouTube/YouTube Music InnerTube endpoints and comprehensive rights for remotely supplied music, artwork, metadata, and lyrics remain unresolved. This release does not establish permission or rights, and provider behavior may change or stop working. EchoWave does not host music and is not an official YouTube client. See [provider notes](../INNER_TUBE_NOTES.md) and the [risk register](../RISK_REGISTER.md).

## Privacy

EchoWave has no analytics backend and does not report installs, app opens, listening activity, or user identifiers to the maintainer. The update checker reads public GitHub release metadata; tapping the update link opens the download website. See [Privacy](../PRIVACY.md) for details.

## Verification

The release workflow attaches the signed APK and its SHA-256 checksum. Build, lint, unit-test, bundle, signature, website, and connected-device outcomes are recorded in the [test plan](../TEST_PLAN.md).
