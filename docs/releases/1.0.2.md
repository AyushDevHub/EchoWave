# EchoWave 1.0.2

EchoWave 1.0.2 is a free, independent Android music player. It is not affiliated with or endorsed by YouTube, Google, or Spotify.

## What's new

- Added aggregate download counts for the latest APK in About. This is a GitHub download counter, not install or active-user analytics; EchoWave does not collect app-use events.
- Added local update notifications when the app is opened and a newer release is available. Android notification permission applies. Notifications are not remote push and no APK is silently downloaded or installed.
- Expanded taste setup with a broader Bollywood artist picker, catalog artwork, and progressive suggestions. Artist search uses the catalog's artist filter.
- Added a queue refresh action, issue/feature-request shortcuts, and updated privacy and project documentation.
- Includes the playback, queue, listening-summary, offline user-audio import, and recommendation improvements listed in the [changelog](../CHANGELOG.md).

## Install

Download `EchoWave-1.0.2.apk` from this release's Assets. Android 8.0 (API 26) or newer is required. Android may ask you to allow installation from your browser or file manager. Updating over an existing install with the same signing key preserves local app data; do not uninstall first.

## Important provider and content notice

The project has not resolved authorization to use its undocumented YouTube/YouTube Music InnerTube endpoints, nor comprehensively cleared rights for remotely supplied music, artwork, metadata, and lyrics. The maintainer requested publication while these issues remain open. This release does not establish permission or rights, and provider behavior may change or stop working. EchoWave does not host music and is not an official YouTube client. See [provider notes](../INNER_TUBE_NOTES.md) and the [risk register](../RISK_REGISTER.md).

## Privacy

EchoWave has no analytics backend and does not report installs, app opens, listening activity, or user identifiers to the maintainer. The download number is the public GitHub asset counter only. See [Privacy](../PRIVACY.md) for network and local-storage details.

## Verification

The release workflow attaches the signed APK and its SHA-256 checksum. Build, lint, unit-test, bundle, signature, and connected-device outcomes are recorded in the [test plan](../TEST_PLAN.md).
