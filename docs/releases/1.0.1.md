# EchoWave 1.0.1

EchoWave 1.0.1 is a free, independent YouTube Music client release. The project does not sell the app and is not affiliated with or endorsed by YouTube or Google.

## Changes

- Added a compact Home-screen update chip that checks GitHub Releases and opens the release page when a newer APK is available.
- Expanded discovery with typed search filters, album detail track lists, browse collections, and seed-based radio autoplay.
- Added an on-device listening profile and personalized radio ranking.
- Improved lyrics track-change handling and playback seek behavior.
- Removed three unused MP3 resources from the current source tree.

## Install

Download `EchoWave-1.0.1.apk` from the Assets section and install it on Android 8.0 (API 26) or newer. Android may ask you to allow installation from your browser or file manager. Installing over v1.0.0 with the same signing key preserves app data.

## Provider and rights notice

EchoWave uses undocumented YouTube/YouTube Music InnerTube endpoints for discovery and playback, including background audio. No provider authorization is documented, and content-rights review remains unresolved. This release was published with those questions open. The project is free and does not sell the app; that does not establish provider authorization or rights. EchoWave is not an official YouTube client and is not affiliated with or endorsed by YouTube or Google. See the [provider integration notes](../INNER_TUBE_NOTES.md) and [risk register](../RISK_REGISTER.md).

The app does not host music. Remote services provide track streams, artwork, and metadata. Provider behavior may change or stop working without notice.
