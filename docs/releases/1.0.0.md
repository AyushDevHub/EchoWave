# EchoWave 1.0.0

First public APK release. This signed APK includes the personalized home screen, selectable themes, search and browse collections, local library, lyrics presentation, and Media3 playback controls.

## Install

Download `EchoWave-1.0.0.apk` from the Assets section and install it on Android 8.0 (API 26) or newer. Android may ask you to allow installation from your browser or file manager.

## Important provider note

EchoWave currently uses unofficial YouTube/YouTube Music InnerTube endpoints for discovery and playback. This is not an official YouTube client or a supported public API. The app is not affiliated with or endorsed by YouTube or Google. Review YouTube's [Developer Policies](https://developers.google.com/youtube/terms/developer-policies) and applicable terms before use. Publishing this APK does not indicate provider authorization.

The APK is signed with the EchoWave release key. Verify it using the included SHA-256 checksum. The project maintainers do not host or distribute music.
